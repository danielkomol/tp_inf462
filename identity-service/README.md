# identity-service

## Description

Gestion de l'authentification et de l'autorisation. Responsable de l'émission et de la validation des tokens JWT, de la gestion des rôles (Client, Admin, Opérateur, Agent) et du support multi-mécanismes : login/password, OTP, 2FA.

## Technologie

- Java
- Spring Boot
- Spring Security / OAuth2
